# Требования к сервису оплаты (Payment API)

Эндпоинт: `POST /api/v1/pay`

Бизнес-правила:
1. При сумме заказа свыше 5000 рублей система обязана запросить 3DS-подтверждение (статус 202 Accepted).
2. Если передана отрицательная или нулевая сумма заказа, API возвращает ошибку 400 Bad Request с кодом `INVALID_AMOUNT`.
3. Валюта по умолчанию — RUB. При передаче неподдерживаемой валюты возвращается 422 Unprocessable Entity.
