# Спецификация сервиса оплаты (/api/v1/pay)

- [REQ] [payments] Эндпоинт `POST /api/v1/pay` принимает JSON с полями `amount` (число > 0) и `currency` (строка).
- [REQ] [payments] Стандартный лимит без подтверждения: для всех клиентов платежи до 5000 RUB включительно проходят сразу со статусом `200 OK`.
- [REQ] [payments] Порог 3DS: для платежей строго больше 5000 RUB требуется подтверждение 3DS — сервис возвращает статус `202 Accepted`.
- [REQ] [payments] Валюта: поддерживается только `RUB`. При передаче любой другой валюты (например, `USD` или `EUR`) сервис возвращает `422 Unprocessable Entity`.
- [REQ] [payments] Валидация суммы и тела: при `amount <= 0`, пустом теле или битом JSON сервис возвращает ошибку валидации `400 Bad Request` или `422 Unprocessable Entity`.
